🎲 Random Generator

A simple desktop application for generating pseudo-random numbers with a clean graphical user interface.

Built with Python, this project provides an easy way to generate random numbers without relying on command-line interaction.

✨ Features
🎲 Generate pseudo-random numbers
🖥️ Simple graphical user interface
⚡ Lightweight and easy to run
🐍 Built with Python
📦 No external dependencies required

🚀 Getting Started
Prerequisites

Make sure you have Python 3.x installed on your system.

You can check your Python version with:

python --version
Installation

Clone the repository:
git clone https://github.com/spielking/random_generator.git

Navigate to the project directory:
cd random_generator
Run the application

Start the application with: python main.py

🛠️ Technologies
Python 3
Python GUI toolkit
Pseudo-random number generation
🎯 Purpose

This project was created as a small Python application for experimenting with random number generation and graphical user interfaces.
It can also serve as a simple example for beginners who want to explore Python desktop applications.
